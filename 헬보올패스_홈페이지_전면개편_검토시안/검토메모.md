# 헬보올패스 홈페이지 전면 개편 검토 시안

## 시안 범위

- 단일 페이지 반응형 HTML/CSS/JavaScript 시안
- 메인 → 집·회사 주변 지점 선택/등급 추천 → 실제 지점 소개 구조 → 올패스 소개 → 등급 비교 → 공지/FAQ/고객지원
- 지점 4개(가락점·여의도역점·강남역점·가양역점)를 이용한 등급 추천 상호작용 예시
- 평일·주말·출장 멤버십 탭, 모바일 메뉴, FAQ 아코디언
- 실제 운영 사이트 수정 및 배포 없음

## 2026-09-14 공식 사이트 확인 결과

1. 메인에는 “전국 80여개 지점”이 표시되지만, 같은 페이지의 띠 문구 및 등급 상세에는 “전국 71개 지점/전체 71곳”이 표시됩니다.
2. 공식 상단 공지는 평택역점·대전시청점·용문역점이 2026-07-01부터 폐점으로 인해 올패스 이용 불가라고 안내합니다.
3. 등급별 지점 목록에는 평택역점과 대전시청점이 여전히 포함되어 있어 공지와 목록 간 불일치가 있습니다.
4. 공식 페이지는 5개 등급(S-Premium, Premium, Gold, Silver, Black)을 안내하며, 높은 등급은 해당 등급 이하 지점을 이용하는 구조입니다.
5. 공식 페이지는 지점 등급이 3개월 단위로 변경될 수 있고, 이에 따라 이용 가능 지점이 바뀔 수 있다고 안내합니다.

따라서 본 시안은 지점 수를 확정 표기하지 않았고, 폐점 공지를 우선 노출했으며, 등급별 이용 원칙만 확정형 UI로 구성했습니다.

## 운영 반영 전 필수 확인

- 본사 기준 활성 지점 마스터와 공식 홈페이지 지점 목록 대조
- 폐점/휴점/신규 오픈 상태값 분리 및 자동 공지 연동
- 각 지점 등급, 주소, 운영시간, 전화번호, 이용 종목 최종 검증
- 실제 지점 사진 원본과 촬영일/승인 여부 등록
- 고객센터 운영시간, 문의 채널, 환불·이용 제한 정책 확정
- 가격 노출 시 공식 가격표 및 프로모션 유효기간 검증

## 파일 구성

- `dist/index.html` — 페이지 구조와 콘텐츠
- `dist/styles.css` — 데스크톱/모바일 반응형 디자인
- `dist/script.js` — 지점 선택, 등급 추천, 탭, 모바일 메뉴
- `dist/assets/` — 시안용 브랜드 그래픽 3종

`dist/index.html`을 브라우저에서 열면 시안을 확인할 수 있습니다.
