# **App Name**: GymFlex Pass

## Core Features:

- Pass Overview: Showcase the 'GymFlex Pass' benefits at a glance with a headline: “One Pass, Access 100 Gyms Nationwide”, and a subhead: “GymFlex Pass gives you the freedom to workout anywhere.” Includes 'Join Now' and 'Find Gyms' CTA buttons.
- Step-by-Step Guide: Present a 4-step guide with illustrative icons, making it easy to understand the process: 1. Register at your local branch, 2. Choose the GymFlex Pass, 3. Check in with the Bro-Z app, 4. Workout freely at various locations.
- User Spotlights: Display user testimonials and authentic photos in a visually engaging layout to build trust, such as: “I can now workout in both Gangnam and Bundang!”, “I used to miss workouts when traveling for work, but not anymore!”
- FAQ Section: Create a dedicated section for FAQs, ensuring key questions are answered directly on the page, such as: “How do I register?”, “Can existing members switch?”, “How do I use premium locations?”
- Promotions Display: Promote current offers with dynamic banners, clearly highlighting the benefits and terms: Nationwide open experience event for 2 months, Instagram hashtag event, Stamp event with GymFlex merchandise.
- CTA Buttons: Incorporate 'Join Now' and 'Find Gyms' buttons with strategic placement.
- Smart Gym Finder: Recommend gyms to the user based on a GPS location provided. The LLM will act as a tool which uses distance, membership level, and popularity to make its recommendation. Display the nearest locations, considering the user’s plan level and preferences. Allow filtering by gym tier: [Black] [Silver] [Gold] [Premium] [S Premium].

## Style Guidelines:

- Primary color: Deep navy blue (#2E3192) for a sense of sophistication and trust.
- Background color: Light desaturated navy (#D8D9E9) to maintain the sophisticated tone while providing a gentle backdrop.
- Accent color: Lime green (#BFFF00) to inject energy and highlight important interactive elements like CTAs.
- Employ a modern, sans-serif typeface to ensure readability and convey a sense of contemporary style.
- Utilize custom, playful illustrations to add character to the GymFlex Pass benefits and step-by-step guides.
- Employ rounded card layouts for a modern, friendly user interface that resonates with the 20-30s female target demographic.
- Subtle transitions and animations will create a smooth, engaging user experience throughout the site.
